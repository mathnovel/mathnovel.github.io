# 1 氙灯方案（传统的多晶硅光伏使用最多）

氙灯方案是多晶硅光伏电池、封装组件从实验室研发、工艺校验到量产质检、权威认证的绝对主流方案，也是晶硅光伏行业发展数十年沉淀下来的标准化、适配性最优的光源技术。核心原因在于多晶硅材料的光电响应特性、量产测试需求、封装组件的检测标准，与校正后氙灯的光谱特性、光斑特性、工作模式高度契合，是LED、金卤灯、等离子灯无法替代的传统光伏基准方案。

## 1.1 氙灯方案的模拟原理

<img src= "/assets/img/100/1.jpg" />


氙灯发光是通过高压短弧氙气放电发光 ，这种方式发出来的光线，从紫外 300nm、可见光一直到 2500nm 近红外都是连续谱，配合滤光片后， 在光谱连续性和匹配度上十分十分优秀。

但是单纯会发光还不够，如果要达到工业级的使用标准，大概需要用下面三个部分来实现：
+ 光源发光
+ 光谱校正机理
+ 光路匀光输出

## 1.2  氙灯方案的优点

1. **光谱连续性最好**
从紫外 300nm、可见光一直到 2500nm 近红外都是连续谱，没有 LED 那种分立峰。配合 AM1.5 滤光片后，可以做到AAA级光谱匹配
1. **紫外波段天然充足**
氙灯本身就输出较强 UV‑A、UV‑B，不需要额外增加紫外光源，适合光老化、材料耐候测试。
1. **容易做大功率、大面积光斑**
单灯可以做到 1‑6kW，多灯阵列可以实现平方米级辐照面，满足组件级光伏测试。
1. **光谱随输出功率变化相对小**
在工作区间内，改变输出光强，光谱形状变化不大。

## 1.3  氙灯方案的缺点

1. **灯泡寿命短，耗材成本高**
常规 500‑1200 小时，大功率水冷氙灯甚至只有几百小时；灯泡老化后光谱漂移、光斑偏移，需要定期更换灯泡 + 重新标定。
2. **发热量巨大，散热压力极高**
大功率氙灯 80% 以上能量变成热；大功率机型必须水冷 + 强排风；设备体积大。
3. **不能瞬时开关**
需要预热，熄灭后要冷却才能二次启动，不支持快速频闪、脉冲模式以外的瞬态开关。
4. **光谱不可独立调节**
只能整体调亮调暗，不能单独增强 / 减弱紫外、红外等某一波段，不能模拟晨昏、阴天光谱变化。
5. **会产生臭氧**
短波紫外电离空气产生臭氧，设备需要排风；灯泡外壳石英老化后 UV 输出会衰减。
6. **电源复杂**：需要专用氙灯直流稳压电源，启动有高压触发。

>结论：强大，也很昂贵和复杂

# 2  金卤灯方案 

<img src= "/assets/img/100/3.jpg" />

## 2.1  金卤灯方案的发光原理

金属卤化物灯（简称金卤灯）太阳光模拟器，属于气体放电光源，核心原理是**汞蒸气电弧放电 + 金属卤化物解离发光 + 光学滤光片光谱校正**，依靠多种金属原子特征谱线叠加形成接近太阳光的复合光谱，再通过滤光整形，用于光伏器件的光照模拟测试。

灯管内部充入汞、惰性气体（氩气等）以及多种金属卤化物（碘化铟、碘化铊、碘化钠等）。点灯初期，镇流器提供高压击穿管内气体，先形成氩气放电，灯管升温；随着管内温度上升，液态汞蒸发形成汞蒸气，建立汞电弧放电，产生基础的蓝白色线状光谱。
电弧中心温度可达数千 K，高温会让管壁附近的金属卤化物蒸发、扩散进入电弧高温区，发生解离：金属卤化物分子分解为**金属原子 + 卤素原子**。

解离出来的各类金属原子在电弧中被高能电子激发，电子跃迁释放光子，各自发射对应波长的特征谱线（铟、铊、钠等分别贡献蓝、绿、黄、红波段）。
不同金属卤化物配方，决定各波段谱线强弱。汞本身提供紫外、蓝波段，添加的金属元素补齐可见光各颜色谱线，**大量线状谱叠加在一起，形成近似连续的复合光谱**。

> 
> 注意：它本质仍是线状谱叠加，不是氙灯那种真正连续等离子体光谱，在部分波段存在光谱缺口或者尖峰，原生光谱和 AM1.5 标准太阳光谱存在明显差距。

当金属原子扩散到温度较低的管壁区域，会重新和卤素原子复合变回金属卤化物.

## 2.2  金卤灯方案的优点

1. **红外光谱非常平滑连续**
> 700‑2500nm 近‑中红外连续黑体谱，红外部分非常贴近太阳光。

1. **光源成本极低**，灯泡便宜，电源简单。
2. 色温可调依靠改变工作电流，黑体光谱形态保持连续。
3. 无臭氧产生。


## 2.3 缺点

1. **原生几乎无紫外（300‑400nm 缺失）**
必须额外外挂 UV 光源补紫外，补光之后紫外与可见光 / 红外是两套独立光源，**很难做到全视场光斑均匀匹配**，这是卤素方案最大痛点。
2. **工作色温偏低**
额定工作下一般 2800‑3200K；要模拟 5500K 太阳光，需要用滤光片大量切掉可见光红外，光效暴跌，能量浪费严重。
3. **发热极其恐怖**
绝大部分电能转为红外热辐射，样品会被明显加热，产生**热效应干扰**，做光化学实验时分不清是光作用还是加热作用。
4. **寿命中等**：几百‑2000 小时，电流越大寿命越短。
5. **光谱漂移明显**：电压波动、灯丝老化，色温、光谱同步漂移；需要频繁标定。
6. **无法达到 AAA 级光谱匹配**，只能做简易模拟，**不能用于光伏计量校准**。

> 
> 适用：低成本光照箱、红外重点测试场景；经常和 LED 组合使用：卤素负责红外，多通道 LED 补齐 UV‑VIS，弥补各自短板。

# 3 LED阵列方案

LED 阵列太阳光模拟的构想最早在 2003 年被提出，由日本东京农工大学完成初代原理样机。2003–2010 年属于实验室原型探索期，受限于 LED 发光效率、可用波段数量不足，光谱匹配度有限，仅用于基础电池测试研究，没有商业化产品。2012 年后，随着高功率、多波段 LED 器件技术进步，多通道独立调光与光谱拟合算法快速成熟，LED 太阳模拟器进入技术快速迭代阶段。2017–2018 年，商用化设备正式推向市场；2020 年以后，伴随钙钛矿、叠层光伏等新型电池研究热潮，LED 阵列方案凭借低热负载、光谱可编程、动态可调的独有优势快速兴起，成为新型光伏器件实验室性能测试的首选方案。

## 3.2 LED 阵列方案的优点

1. 卓越的可编程性与动态光谱模拟：通过独立控制不同波段（如紫外、可见光、近红外等）的多通道 LED，不仅能高精度拟合标准太阳光谱（如 AM1.5G），还能随时通过软件编程模拟真实一天的动态光照变化（例如：一键切换清晨、正午、傍晚的光谱与光强曲线），这是传统机械滤光片根本无法做到的。
2. 超长寿命与“零”耗材：传统氙灯寿命通常仅有 1,000 小时左右，而工业级 LED 阵列的寿命通常可达 20,000 至 50,000 小时以上。这意味着客户买回去之后，几乎不需要像过去那样频繁、高昂地定期更换灯管，大幅降低了长期的运维成本。
3. 真正的“冷光源”，热辐射极低：发光效率远高于传统热光源，电能大部分转化为光而非红外热量。它不会像氙灯或卤素灯那样产生剧烈的热辐射去烘烤样品，从而彻底消除了热效应对精密光伏、材料老化或生物实验的干扰，也免去了笨重噪音大的水冷机。
4. 即开即用与无极调光：传统氙灯点亮需要预热和触发高压，开关受寿命限制；而 LED 阵列可以毫秒级瞬间点亮、关闭，并且在全量程内实现无级、平滑的光强调节，输出极其稳定。
5. 安全环保、无高压与臭氧隐患：采用低压直流驱动，没有传统氙灯工作时的高压爆裂风险，同时不产生臭氧，对实验室的安全和环境更加友好。因为只需要普通的市电即可使用，没有太高的环境要求，这样可以在很低成本的条件下就可以实现太阳光的模拟
6. 具备作为物联网接入的特性：电源的调整，传感器的读数，温度的监控，都可以通过编程来实现，这种模式远比前面几种模式更契合现代自动化的特性。


## 3.3 LED 阵列方案的缺点

1. 光谱为离散谱，拟合光谱复杂:LED 是窄带单色发光器件，阵列是**多种分立波长 LED 叠加合成光谱**，并非氙灯那种连续等离子光谱,需要选用多种波长的灯珠来组合，才能拟合出匹配的光谱。 深紫外 LED 电光转换效率低、输出光强弱，补齐紫外波段成本高.
2. 大面积高均匀光斑实现难度大：灯珠是空间离散点光源，不同波长灯珠需要交错混排。小光斑（≤50×50mm）容易做到 A+/AAA；**当光斑扩大到组件级别（如 1600mm×1000mm），空间光谱均匀性难保证**：容易出现局部区域某一波段偏强 / 偏弱，样品面上光谱分布不一致。
3. 需要额外的编程来驱动，通道驱动复杂：不同的led组合才能拟合出合适的光谱，这需要对电源有调配控制能力，而不是买回来装上去直接使用。

# 4 等离子灯方案

等离子灯方案的原理是微波激发无极等离子体发光，无电极，区别于氙灯靠电极电弧放电。
这个方案是近年才开始探索的方案，目前未有详实数据。
可以知道的数据就是，整个方案类似氙灯方案，灯的价格比较高，据说寿命比氙灯长。
